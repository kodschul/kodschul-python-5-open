# Lab 1.1 – Übung: Was ich mit Python automatisieren will

**Dauer:** ca. 10 Minuten
**Ändert die Zahlenraten-Projektbasis?** Nein — die Übung sammelt Ideen; das Spiel beginnt in Lab 2.1.

## Vorbereitung

- Die Tabellen „Einsatzgebiete“ und „Stärken und Grenzen“ aus der Theorie liegen offen.
- Papier oder eine leere Textdatei für die eigene Tabelle.

## Aufgaben

1. Notiere drei Aufgaben aus Studium oder Alltag, die sich regelmäßig wiederholen und am Rechner erledigt werden (z. B. Dateien umbenennen, Noten ausrechnen, Daten aus Tabellen zusammentragen).
2. Übertrage sie in diese Tabelle und ergänze, wie oft sie anfallen:

   | Aufgabe | Wie oft? | Einsatzgebiet | Was Python übernehmen würde |
   | --- | --- | --- | --- |
   | | | | |
   | | | | |
   | | | | |

3. Ordne jeder Aufgabe ein Einsatzgebiet aus der Theorie zu (Automatisierung, Administration und DevOps, Datenanalyse, Web, KI und maschinelles Lernen, Lernen und Prototypen).
4. Beschreibe in der letzten Spalte in einem Satz, was ein Python-Skript erledigen würde: Was liest es ein, was tut es damit, was gibt es aus?
5. Markiere die Aufgabe, die am meisten Zeit sparen würde.

## Checkpoint

- Die Tabelle hat drei vollständig ausgefüllte Zeilen.
- Jede Zeile nennt genau ein Einsatzgebiet.
- Jede Beschreibung in der letzten Spalte nennt Eingabe, Verarbeitung und Ausgabe.

## Abschlusskriterien

- Eine Aufgabe ist als größte Zeitersparnis markiert.
- Die Tabelle ist gespeichert oder aufgeschrieben; sie dient am Kursende als Liste eigener Projektideen.

## Erweiterung

Ergänze für die markierte Aufgabe eine Zeile „Grenze“: Was könnte ein Skript dabei nicht leisten (z. B. eine Entscheidung, die Fachwissen braucht)?
