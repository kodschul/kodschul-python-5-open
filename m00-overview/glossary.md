# Glossar: Python Programmierung

| Begriff | Bedeutung | Lab |
| --- | --- | --- |
| abstrakte Klasse | Basisklasse, von der sich kein Objekt erzeugen lässt | 11.3 |
| API | Schnittstelle, über die Programme Daten abfragen | 16.1 |
| `argparse` | Modul, das Kommandozeilen-Argumente prüft und umwandelt | 14.2 |
| Attribut | Wert, den sich ein Objekt merkt („weiß“) | 9.1 |
| Ausnahme (Exception) | Signal „hier geht es nicht weiter“, mit Typ und Meldung | 7.1 |
| Bedingung | Ausdruck, der `True` oder `False` ergibt | 3.1 |
| Bibliothek | fertiger, wiederverwendbarer Code für eine Aufgabe | 1.1 |
| Comprehension | baut in einer Zeile eine neue Sammlung aus einer Folge | 12.1 |
| Context Manager | bereitet im `with`-Block vor und räumt danach sicher auf | 13.2 |
| CSV | Tabelle als Text, Werte durch Trennzeichen getrennt | 8.3 |
| Dataclass | Klasse, deren `__init__`, `__repr__`, `__eq__` Python erzeugt | 11.2 |
| DataFrame | Tabelle mit benannten Spalten in pandas | 19.2 |
| Datentyp | Art eines Wertes, z. B. `int`, `str`, `bool` | 2.2 |
| Debugger | hält ein Programm an und lässt hineinschauen | 7.4 |
| Decorator | Funktion, die eine Funktion um Verhalten erweitert | 13.1 |
| Dictionary (`dict`) | Sammlung von Paaren Schlüssel → Wert | 4.3 |
| Einrückung | Leerzeichen am Zeilenanfang; in Python Teil der Syntax | 2.1 |
| f-String | Text mit `f` davor; `{name}` wird durch den Wert ersetzt | 2.2 |
| Funktion | benanntes Werkzeug, aufgerufen mit Klammern | 2.1 |
| Generatorfunktion | Funktion mit `yield`, liefert Werte erst auf Anfrage | 12.3 |
| Gültigkeitsbereich (Scope) | Bereich, in dem ein Name bekannt ist: lokal oder global | 5.3 |
| HTTP | Regeln für Anfrage und Antwort im Web | 16.1 |
| Interpreter | führt Quelltext Zeile für Zeile aus | 1.1 |
| Iterator | merkt sich die Position und liefert das nächste Element | 12.3 |
| JSON | Textformat für verschachtelte Daten | 8.2 |
| Kapselung | Daten im Objekt, Änderung nur über Methoden | 9.3 |
| Klasse | Bauplan für Objekte, wie eine Ausstechform | 9.1 |
| Kodierung (Encoding) | Regel, wie Zeichen zu Bytes werden; meist UTF-8 | 8.1 |
| Komposition | Objekt hält andere Objekte und nutzt sie („hat ein“) | 10.3 |
| `lambda` | kleine Funktion ohne Namen aus einem Ausdruck | 12.2 |
| Liste (`list`) | geordnete, veränderbare Sammlung | 4.1 |
| Magic Method | Methode wie `__str__`, die Python selbst aufruft | 11.1 |
| Methode | Funktion, die zu einem Wert gehört: `name.upper()` | 2.4 |
| Modul | `.py`-Datei, deren Inhalt sich importieren lässt | 3.2 |
| Objekt | Wert im Speicher mit Typ und Inhalt; nach Klassen-Bauplan gebaut | 5.3 |
| Paket | installierbare Bibliothek; im Code: Ordner mit Modulen | 1.2, 6.1 |
| pandas | Bibliothek für Tabellen | 19.2 |
| Parameter | Platzhalter-Name in der `def`-Zeile | 5.1 |
| Pattern Matching | Fallunterscheidung nach der Form eines Werts (`match`) | 13.3 |
| PEP 8 | offizieller Stil-Leitfaden für Python-Code | 2.1 |
| `pickle` | verwandelt Python-Objekte in Bytes und zurück | 17.3 |
| `pip` | installiert Pakete von PyPI | 1.2 |
| Platzhalter `?` | Lücke im SQL-Text, sicher mit einem Wert gefüllt | 18.2 |
| Polymorphie | gleicher Aufruf, anderes Verhalten je Objekt | 10.2 |
| Primärschlüssel | Spalte, die jede Zeile eindeutig macht | 18.1 |
| PyPI | öffentlicher Katalog für Python-Pakete | 6.2 |
| Regulärer Ausdruck (Regex) | Suchmuster für die Form eines Textes | 15.2 |
| REPL | interaktiver Modus: Zeile eingeben, Ergebnis sehen | 1.2 |
| Rückgabewert | Wert, den ein Funktionsaufruf mit `return` liefert | 5.1 |
| Schleife | Block, der mehrmals hintereinander läuft | 3.3 |
| Set | ungeordnete Sammlung ohne Duplikate | 4.2 |
| SQL | Sprache zum Anlegen und Abfragen von Tabellen | 18.1 |
| SQL-Injection | Angriff: Eingabe wird Teil des SQL-Befehls | 18.2 |
| SQLite | Datenbank in einer Datei, in Python enthalten | 18.1 |
| String (`str`) | Text in Anführungszeichen | 2.1 |
| Traceback | Fehlerblock vom Programmstart bis zur Abbruchstelle | 7.1 |
| Tupel (`tuple`) | geordnete, unveränderliche Gruppe | 4.2 |
| Type Hint | Typangabe wie `level: str`; Python prüft sie nicht | 5.2 |
| Variable | Name, der auf einen Wert zeigt, wie ein Etikett | 2.2 |
| virtuelle Umgebung (venv) | Ordner `.venv` mit eigenen Paketen pro Projekt | 1.2 |
